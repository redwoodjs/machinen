# Goal 016 — Add pipes as the third portable restore adapter/resource

## Status

Completed in this change.

## Objective

Prove the portable restore adapter path can handle a paired Linux resource by adding pipes as the third Level 4 adapter/resource after ping and eventfd.

## Pipe product boundary

The new adapter supports the narrow Level 4 pipe subset:

- exactly one read end and one write end;
- distinct bounded source fd numbers;
- empty pipe buffer;
- peer lifetime known open;
- waiters known empty;
- read end readiness known not-readable;
- flags limited to close-on-exec;
- no active pipe read/write syscall;
- target-native pipe recreation and verifier output.

Unsafe neighboring states fail closed with stable refusal codes:

- `pipe-fd-pair-invalid`;
- `pipe-buffered-data-unsupported`;
- `pipe-peer-lifetime-unsupported`;
- `pipe-waiters-unsupported`;
- `pipe-readiness-unsupported`;
- `pipe-unsupported-flags`;
- `pipe-active-syscall-unsupported`;
- target architecture/verifier mismatches.

## Adapter integration

`machinen restore` now has three portable restore adapters:

1. `ping-level4-socket-reconstruction-v1`;
2. `eventfd-counter-v1-nonsemaphore-no-waiters`;
3. `pipe-pair-v1-empty-no-waiters`.

The pipe adapter implements the same hooks as ping and eventfd:

- `detect` — finds `portable-pipe.json`;
- `validate` — validates descriptor, target architecture, and verifier output;
- `plan` — builds descriptor path, target-native Perl pipe command, log path, and summary builder;
- `foregroundRestore` — uses the generic foreground portable workload runner;
- `detachedRestore` — uses the generic detached portable workload runner;
- `verify` — checks target PID and `MACHINEN_PIPE_RESTORED readFd=<n> writeFd=<n>` output;
- `refuse` — emits the stable pipe restore refusal summary.

## Public surface

A new capture surface writes the descriptor bundle:

```sh
machinen capture pipe \
  --out ./pipe.portable \
  --source-arch arm64 \
  --target-arch amd64 \
  --source-verifier-output ./pipe.verify \
  --read-fd 10 \
  --write-fd 12
```

Restore uses the generic adapter dispatch:

```sh
machinen restore ./pipe.portable --target-arch amd64 --json
```

Detached JSON restore boots a target VM, creates a target-native pipe pair, verifies the empty/not-readable state, and returns the restored VM identity.
