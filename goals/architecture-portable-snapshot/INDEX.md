# Architecture-portable snapshot goals

These active goals are the proof contract for any row that claims an actual
architecture-portable continuation. Each future continuation profile must satisfy
all of these goals for its own state model before it can count as a successful
continuation.

Archived goals 001-010 from the first roadmap pass are in
`goals/archive/architecture-portable-snapshot-001-010/`.

Parent roadmap issue: https://github.com/redwoodjs/machinen/issues/810
