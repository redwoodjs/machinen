# Goal 007: Phase 4 — TCP listener-only Level 4 reconstruction

## Objective

Create the TCP listener-only Level 4 graduation slice. This is intentionally not
active TCP continuation. The first useful socket product candidate is a listener
with explicit bind/backlog state and an empty accept queue.

## Status language

| Field                   | Target while this goal is in proof mode                                            |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `evidenceStatus`        | `proof` for accepted listener reconstruction; `refusal` for unsafe neighbors       |
| `productSupport`        | `not-yet-supported` for proof rows; `unsupported` for refusal rows                 |
| `implementationLevel`   | `not-implemented` for proof rows; `level-0-fail-closed-discovery` for refusal rows |
| `graduationTargetLevel` | `level-4-kernel-resource-reconstruction`                                           |

## Accepted descriptor shape

Start with listener-only TCP descriptors:

- explicit address family and socket type;
- explicit bind address and port;
- explicit namespace/route policy;
- explicit backlog;
- explicit socket options such as reuseaddr when accepted;
- empty accept queue;
- no active connections;
- target-native listener recreation verifier.

## Refusals

Refuse fail-closed for:

- active established connections;
- non-empty accept queues;
- ambiguous bind addresses;
- missing or dynamic ports;
- unsupported socket options;
- partial send/recv state;
- active accept/connect/syscall state.

All refusal rows must keep `productSupport=unsupported` and
`migrationCompleted=false`.

## Graduation requirements

TCP listener-only can move from proof to support only after:

1. listener descriptors are accepted by the public snapshot/restore path;
2. target recreation verifies bind, port, backlog, namespace, and options;
3. active TCP remains explicitly unsupported or has a separate goal;
4. all unsafe neighbors remain checked refusals;
5. Node/libuv server sockets consume the generic listener descriptor.

## Non-goals

- No active TCP stream continuation.
- No connection queue migration beyond empty accepted policy.
- No transparent port rebinding without verifier evidence.
