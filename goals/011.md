# Goal 011 — Make ping the first Level 4 portable machine snapshot workload

## Status

Completed in this change.

## Objective

Use ping as the first product-supported Level 4 **portable machine snapshot** workload.

This replaces the ping-specific Level 2 semantic product claim with a machine-transport claim:
`machinen snapshot` captures the supported ping machine subset as a portable Level 4 resource descriptor, and `machinen restore` verifies the target-native reconstruction.

## Supported machine subset

The portable snapshot path supports only the narrow ping workload where the guest exposes a checked descriptor for:

- datagram ping socket or raw ICMP socket;
- loopback route and target loopback namespace;
- preserved ICMP echo identifier and sequence;
- empty receive queue;
- no in-flight ICMP packets;
- no active `recvmsg` frame;
- credential/capability mapping available on the target;
- target-native verifier evidence at restore time.

## Public surfaces

Snapshot path:

```sh
MACHINEN_SNAPSHOT_ENGINE=portable machinen snapshot <vm> ./ping.portable
machinen restore ./ping.portable --target-arch <arm64|amd64> [--target-verifier-output ./target.verify]
machinen support --profile ping-level4-socket-reconstruction-v1 --json
```

The older `machinen capture ping-socket` descriptor route remains a lower-level product descriptor helper, but the product claim is now portable-machine snapshot support for this workload.

## Stable refusals preserved

Unsupported neighboring states remain fail-closed with `migrationCompleted=false`:

- no supported ping descriptor inside the machine;
- unread receive queue;
- in-flight ICMP packets;
- active `recvmsg`;
- ambiguous route or network namespace;
- missing credential/capability mapping;
- unsupported raw socket options;
- target verifier mismatch.

## Reusable Level 4 transport machinery

Goal 011 introduces a portable machine transport manifest that points at the Level 4 resource descriptor. Ping is the first resource family. The same shape is intended for follow-on resources:

- pipes;
- eventfd;
- timerfd;
- TCP listener.
