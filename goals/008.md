# Goal 008: Phase 5 — Node event-loop Level 4 resource map

## Objective

Map Node/libuv event-loop state onto the generic Level 4 resources from earlier
phases. This goal is a planning and integration slice. It should reduce Level 3
runtime-aware debt, not create a Node-specific shortcut.

## Status language

| Field                   | Target while this goal is in planning/proof mode                                      |
| ----------------------- | ------------------------------------------------------------------------------------- |
| `evidenceStatus`        | `planning` for the resource map; `refusal` for unsafe event-loop states               |
| `productSupport`        | `not-yet-supported` for planning rows; `unsupported` for refusal rows                 |
| `implementationLevel`   | `not-implemented` for planning rows; `level-0-fail-closed-discovery` for refusal rows |
| `graduationTargetLevel` | `level-4-kernel-resource-reconstruction`                                              |

## Resource map

Map Node/libuv resources to generic Level 4 descriptors:

- libuv pipes -> Goal 004 pipe descriptors;
- async wakeups -> Goal 005 eventfd descriptors;
- timers -> Goal 006 timerfd descriptors;
- server sockets -> Goal 007 TCP listener descriptors;
- readiness and waiters -> explicit descriptor fields or refusals;
- credentials/namespaces -> shared Level 4 policy.

## Refusals

Refuse fail-closed for:

- active TCP streams;
- child process IPC;
- fs watchers;
- native addon hidden state;
- worker threads;
- inspector/debug state;
- unsupported V8/libuv states;
- dirty persistence or database-like state hidden behind Node.

All refusal rows must keep `productSupport=unsupported` and
`migrationCompleted=false`.

## Graduation requirements

Node event-loop resources can move toward support only after:

1. the generic Level 4 pipe/eventfd/timerfd/listener goals have checked proof and
   refusal rows;
2. Node descriptors reference those generic resources instead of private runtime
   shortcuts;
3. target recreation verifies libuv handle readiness and resource identity;
4. unsafe event-loop neighbors remain checked refusals;
5. public product verbs expose the accepted subset clearly.

## Non-goals

- No arbitrary Node process continuation.
- No V8 heap/native stack translation; that belongs to Level 5.
- No hidden libuv state accepted without a generic descriptor.
