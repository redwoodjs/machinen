# Goal 018 — Add TCP listener as the fifth portable restore adapter/resource

## Status

In progress in this change.

## Objective

Graduate the listener-only slice from Goal 007 into the generic portable restore adapter path. This adds TCP listener-only sockets as the fifth Level 4 adapter/resource after ping, eventfd, pipes, and timerfd.

## TCP listener product boundary

The new adapter supports the narrow Level 4 TCP listener subset:

- IPv4 loopback bind, `127.0.0.1` only;
- static non-zero TCP port;
- explicit backlog in the supported range;
- `SO_REUSEADDR` enabled;
- empty accept queue;
- no active TCP connections;
- no partial send/receive state;
- no active accept/connect/socket syscall;
- target-native listener recreation and verifier output.

Unsafe neighboring states fail closed with stable refusal codes:

- `tcp-listener-address-unsupported`;
- `tcp-listener-port-invalid`;
- `tcp-listener-backlog-out-of-range`;
- `tcp-listener-active-connections-unsupported`;
- `tcp-listener-accept-queue-unsupported`;
- `tcp-listener-unsupported-options`;
- `tcp-listener-partial-io-unsupported`;
- `tcp-listener-active-syscall-unsupported`;
- target architecture/verifier mismatches.

## Adapter integration

`machinen restore` now has five portable restore adapters:

1. `ping-level4-socket-reconstruction-v1`;
2. `eventfd-counter-v1-nonsemaphore-no-waiters`;
3. `pipe-pair-v1-empty-no-waiters`;
4. `timerfd-relative-oneshot-v1-monotonic`;
5. `tcp-listener-v1-loopback-empty-accept-queue`.

The TCP listener adapter implements the same hooks as the earlier adapters:

- `detect` — finds `portable-tcp-listener.json`;
- `validate` — validates descriptor, target architecture, and verifier output;
- `plan` — builds descriptor path, target-native Perl listener command, log path, and summary builder;
- `foregroundRestore` — uses the generic foreground portable workload runner;
- `detachedRestore` — uses the generic detached portable workload runner;
- `verify` — checks target PID and `MACHINEN_TCP_LISTENER_RESTORED ...` output;
- `refuse` — emits the stable TCP listener restore refusal summary.

## Public surface

A new capture surface writes the descriptor bundle:

```sh
machinen capture tcp-listener \
  --out ./tcp.portable \
  --source-arch arm64 \
  --target-arch amd64 \
  --source-verifier-output ./tcp.verify \
  --bind-address 127.0.0.1 \
  --port 18080 \
  --backlog 16
```

Restore uses the generic adapter dispatch:

```sh
machinen restore ./tcp.portable --target-arch amd64 --json
```

Detached JSON restore boots a target VM, creates and listens on a target-native TCP socket, verifies the target output, and returns the restored VM identity.
