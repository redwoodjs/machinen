# Goal 012 — Auto-inspect running ping for portable Level 4 snapshots

## Status

Completed in this change.

## Objective

Make the ping Level 4 portable machine path usable as a real end-to-end workflow:
run `ping` in the guest, then run `machinen snapshot` without manually writing a ping descriptor.

## Product behavior

With `MACHINEN_SNAPSHOT_ENGINE=portable`, `machinen snapshot <vm> <bundle>` now:

1. checks for an explicit descriptor at `/run/machinen/portable-ping-socket.json` or `/tmp/machinen-portable-ping-socket.json`;
2. if none exists, inspects the guest's `/proc` state for exactly one running loopback `ping` process;
3. matches the ping process socket inode against `/proc/net/icmp` or `/proc/net/raw`;
4. requires empty socket queues and no active receive wait;
5. emits the Level 4 `ping-level4-socket-reconstruction-v1` descriptor into the portable machine bundle;
6. leaves unsupported neighboring states as fail-closed snapshot refusals.

## User flow

```sh
machinen boot --detach --name ping-demo -- sleep 1000
machinen exec ping-demo -- 'ping -i 10 127.0.0.1 >/tmp/ping.log 2>&1 &'

MACHINEN_SNAPSHOT_ENGINE=portable machinen snapshot ping-demo ./ping.portable
machinen restore ./ping.portable --target-arch amd64 [--target-verifier-output ./target.verify]
```

The target verifier file must contain the verifier string from the generated bundle descriptor's `sourceVerifierOutput` field or equivalent target-native verifier output.

## Scope

Supported now:

- one running loopback ping process;
- datagram ping sockets via `/proc/net/icmp`;
- raw ICMP sockets via `/proc/net/raw`;
- empty queues;
- no active receive wait;
- default target architecture is the opposite of the source guest architecture;
- optional `MACHINEN_PORTABLE_TARGET_ARCH=arm64|amd64` override.

Still refused:

- zero or multiple ping processes;
- non-loopback destinations;
- non-empty queues;
- active receive wait;
- sockets that cannot be matched to `/proc/net/icmp` or `/proc/net/raw`;
- all non-ping workloads until their Level 4 resource descriptors are implemented.
