# Goal 003: Phase 1 — ping Level 4 socket reconstruction

## Objective

Turn the ping Level 4 matrix row into an executable graduation slice without
claiming product support too early. Existing ping semantic continuation stays
Level 2 product support. The new work targets raw/ping ICMP socket
reconstruction as a Level 4 candidate.

## Status language

| Field                   | Target while this goal is in proof mode                                            |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `evidenceStatus`        | `proof` for accepted socket reconstruction; `refusal` for unsafe neighbors         |
| `productSupport`        | `not-yet-supported` for proof rows; `unsupported` for refusal rows                 |
| `implementationLevel`   | `not-implemented` for proof rows; `level-0-fail-closed-discovery` for refusal rows |
| `graduationTargetLevel` | `level-4-kernel-resource-reconstruction`                                           |

## Accepted descriptor shape

Start with a narrow ping descriptor:

- raw/ping ICMP family/type/protocol;
- ICMP identifier and next sequence;
- explicit destination and route/namespace policy;
- explicit uid/gid and ping group range or capability policy;
- no unread receive queue;
- no in-flight packets;
- no active `recvmsg` or interrupted syscall;
- target-native socket recreation verifier.

## Refusals

Refuse fail-closed for:

- unread receive queue;
- in-flight packets;
- active `recvmsg`;
- ambiguous route or namespace;
- missing credential/capability mapping;
- unsupported raw socket options;
- verifier mismatch.

All refusal rows must keep `productSupport=unsupported` and
`migrationCompleted=false`.

## Graduation requirements

Ping can move from proof to support only after:

1. the descriptor is routed through public product verbs (`machinen capture` or
   `machinen snapshot`, plus `machinen restore`);
2. the target socket is recreated target-natively;
3. the verifier proves identifier/sequence, route, credentials, and queue policy;
4. unsafe neighbors remain checked refusals;
5. docs clearly distinguish Level 2 semantic ping from Level 4 socket support.

At Goal 003 completion time, the checked summary kept existing ping semantic
continuation as `productSupport=supported` at
`implementationLevel=level-2-semantic-continuation`, and the Level 4 socket
reconstruction row as proof/not-yet-supported. Goal 011 supersedes that product
boundary by retiring Level 2 ping product support and making the narrow ping
socket row the supported portable machine Level 4 route. Unsafe neighbors remain
checked refusal rows with `productSupport=unsupported` and
`migrationCompleted=false`.

## Non-goals

- No active TCP continuation.
- No arbitrary raw socket continuation.
- No source-ISA emulation, sidecar output, metadata-only success, or raw
  checkpoint replay.
