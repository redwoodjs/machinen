# Goal 017 — Add timerfd as the fourth portable restore adapter/resource

## Status

Completed in this change.

## Objective

Add timerfd as the fourth Level 4 adapter/resource after ping, eventfd, and pipes. This proves the generic adapter path can handle an event-loop timer fd with target-native reconstruction.

## Timerfd product boundary

The new adapter supports the narrow Level 4 timerfd subset:

- `CLOCK_MONOTONIC` clock;
- relative one-shot timer;
- bounded positive remaining time;
- no interval/periodic mode;
- no unread expirations;
- flags limited to close-on-exec;
- no active timerfd read syscall;
- target-native timerfd recreation and verifier output.

Unsafe neighboring states fail closed with stable refusal codes:

- `timerfd-remaining-time-out-of-range`;
- `timerfd-unread-expirations-unsupported`;
- `timerfd-periodic-unsupported`;
- `timerfd-absolute-unsupported`;
- `timerfd-cancel-on-set-unsupported`;
- `timerfd-clock-unsupported`;
- `timerfd-unsupported-flags`;
- `timerfd-active-read-unsupported`;
- target architecture/verifier mismatches.

## Adapter integration

`machinen restore` now has four portable restore adapters:

1. `ping-level4-socket-reconstruction-v1`;
2. `eventfd-counter-v1-nonsemaphore-no-waiters`;
3. `pipe-pair-v1-empty-no-waiters`;
4. `timerfd-relative-oneshot-v1-monotonic`.

The timerfd adapter implements the same hooks as the earlier adapters:

- `detect` — finds `portable-timerfd.json`;
- `validate` — validates descriptor, target architecture, and verifier output;
- `plan` — builds descriptor path, target-native Perl timerfd command, log path, and summary builder;
- `foregroundRestore` — uses the generic foreground portable workload runner;
- `detachedRestore` — uses the generic detached portable workload runner;
- `verify` — checks target PID and `MACHINEN_TIMERFD_RESTORED ... remainingMs=<n>` output;
- `refuse` — emits the stable timerfd restore refusal summary.

## Public surface

A new capture surface writes the descriptor bundle:

```sh
machinen capture timerfd \
  --out ./timerfd.portable \
  --source-arch arm64 \
  --target-arch amd64 \
  --source-verifier-output ./timerfd.verify \
  --remaining-ms 60000
```

Restore uses the generic adapter dispatch:

```sh
machinen restore ./timerfd.portable --target-arch amd64 --json
```

Detached JSON restore boots a target VM, creates and arms a target-native timerfd, verifies the target output, and returns the restored VM identity.
