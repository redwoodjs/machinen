# Goal 006: Phase 3 — timerfd Level 4 reconstruction

## Objective

Create the timerfd Level 4 graduation slice. timerfd is the smallest timer
primitive needed for a generic runtime event-loop path, but this goal starts as
proof and refusal evidence, not product support.

## Status language

| Field                   | Target while this goal is in proof mode                                            |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `evidenceStatus`        | `proof` for accepted timerfd reconstruction; `refusal` for unsafe neighbors        |
| `productSupport`        | `not-yet-supported` for proof rows; `unsupported` for refusal rows                 |
| `implementationLevel`   | `not-implemented` for proof rows; `level-0-fail-closed-discovery` for refusal rows |
| `graduationTargetLevel` | `level-4-kernel-resource-reconstruction`                                           |

## Accepted descriptor shape

Start with one-shot relative timers:

- explicit clock id, initially monotonic;
- relative remaining time;
- no interval/periodic mode;
- no unread expirations;
- explicit flags;
- target-native timerfd recreation verifier.

## Refusals

Refuse fail-closed for:

- unread expirations/ticks;
- periodic timers;
- absolute timers until clock-drift policy exists;
- cancel-on-set ambiguity;
- unsupported clock ids;
- active read syscall state.

All refusal rows must keep `productSupport=unsupported` and
`migrationCompleted=false`.

## Graduation requirements

timerfd can move from proof to support only after:

1. timerfd descriptors are accepted by the public snapshot/restore path;
2. target recreation verifies clock id, remaining time, flags, and expiration
   policy;
3. periodic and absolute timers are either modeled or refused;
4. all unsafe neighbors remain checked refusals;
5. Node/libuv timers consume the generic timerfd descriptor.

## Non-goals

- No general POSIX timer support.
- No clock namespace migration.
- No silent drain of unread expirations.
