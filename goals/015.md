# Goal 015 — Add the second portable restore adapter/resource

## Status

Completed in this change.

## Objective

Prove the Goal 014 adapter shape is reusable by adding a second portable restore adapter and resource. The resource is eventfd.

## Eventfd product boundary

The new adapter supports the narrow Level 4 eventfd subset:

- bounded nonzero counter (currently <= `UINT32_MAX` for target helper portability);
- semaphore mode off;
- waiters known empty;
- no aliases/duplicate descriptors;
- flags limited to close-on-exec;
- no active eventfd read/write syscall;
- target-native eventfd recreation and verifier output.

Unsafe neighboring states fail closed with stable refusal codes:

- `eventfd-counter-out-of-range`;
- `eventfd-semaphore-unsupported`;
- `eventfd-waiters-unsupported`;
- `eventfd-alias-unsupported`;
- `eventfd-unsupported-flags`;
- `eventfd-active-syscall-unsupported`;
- target architecture/verifier mismatches.

## Adapter integration

`machinen restore` now has two portable restore adapters:

1. `ping-level4-socket-reconstruction-v1`;
2. `eventfd-counter-v1-nonsemaphore-no-waiters`.

The eventfd adapter implements the same hooks as ping:

- `detect` — finds `portable-eventfd.json`;
- `validate` — validates descriptor, target architecture, and verifier output;
- `plan` — builds descriptor path, target-native Perl eventfd command, log path, and summary builder;
- `foregroundRestore` — uses the generic foreground portable workload runner;
- `detachedRestore` — uses the generic detached portable workload runner;
- `verify` — checks target PID and `MACHINEN_EVENTFD_RESTORED counter=<n>` output;
- `refuse` — emits the stable eventfd restore refusal summary.

## Public surface

A new capture surface writes the descriptor bundle:

```sh
machinen capture eventfd \
  --out ./eventfd.portable \
  --source-arch arm64 \
  --target-arch amd64 \
  --source-verifier-output ./eventfd.verify \
  --counter 42
```

Restore uses the generic adapter dispatch:

```sh
machinen restore ./eventfd.portable --target-arch amd64 --json
```

Detached JSON restore boots a target VM, creates a target-native eventfd, verifies the counter/readiness output, and returns the restored VM identity.
