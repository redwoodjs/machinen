# Next thirty move envelope proof ladder

## Goal

Extend `machinen move` proofs by adding thirty more explicit target-native continuation envelopes and fail-closed gatekeepers. The work must deepen regular-file, process-wrapper, listener, and first application/runtime proof coverage without widening into generic process restore, generic Node/runtime restore, generic cross-architecture VM restore, source-ISA emulation, or metadata-only success. Each support row must define a narrow accepted command shape, descriptor state, target loader strategy, visible target proof output, and refusal boundaries. Each gatekeeper row must prove a nearby unsafe shape refuses before target loader launch.

## Stop if

- Any proof would require claiming arbitrary process, VM, ELF, Node, Python, Go, Rust, or runtime cross-architecture restore.
- Any proof requires source-ISA emulation instead of target-native continuation.
- Any proof requires metadata-only success without visible target evidence.
- Any proof requires baking proof-only packages into the base image instead of proof-local VM/overlay provisioning.
- A support row cannot be narrowed to an explicit descriptor state, target loader strategy, and visible target proof output.
- A gatekeeper row cannot prove refusal before target loader launch.
- Required remote host `root@192.168.0.8` is unreachable and remote amd64 evidence cannot be collected.
- A proof row is disproved and cannot be narrowed into a safe envelope in this run.
- The /goal loop reaches 8 agent completion(s) without satisfying the contract.
