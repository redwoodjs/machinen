# Machinen research

This directory holds proof material, checked summaries, harness fixtures, and design notes that are not product documentation.

Use it to preserve evidence and experiments without making them look like supported user workflows.

## Areas

- [Snapshot and move research](./snapshot/README.md) — cross-ISA proofs, refusal evidence, runtime manifests, app harnesses, and checked summaries.
- [Portability research](../portability/research/README.md) — native continuation and binary-refusal experiments.

## Rule

Product-facing docs live under `docs/`. Research evidence lives here. A proof or checked summary does not become product support unless the product docs and `machinen support --json` say so.
