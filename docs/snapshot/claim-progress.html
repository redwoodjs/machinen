Type

The table uses a small basic type set. The detailed category appears in the Subcategory column.

e2e
End-to-end or workload smoke evidence with source/target behavior checks.
command
Unix or product command proof run before capture and/or after restore.
coverage
Ledger, corpus, matrix, or artifact audit evidence.
claim
Claim ladder, product contract, seed matrix, or claim gate.
boundary
Explicit refusal or unsupported-state proof that prevents overclaiming.
resource
File descriptor, kernel resource, or network resource reconstruction proof.
substrate
CPU, memory, stack, bootstrap, and page-state reconstruction substrate proof.
capability
Host/guest capability probe such as eBPF, seccomp, or nested virtualization.
product
Product UX, dependency install, or app/package setup proof.

Progression

0 · not-started
No retained proof artifact yet.
1 · seed-candidate
A scoped idea or fixture exists, but it is not claim-ready.
2 · partial-proof
Some retained evidence exists, but required gates are still incomplete.
3 · verified / passed / verified-seed
The row passed its verifier, but it only changes claims if the whole gate allows it.
4 · refused / forbidden
An explicit unsafe boundary; kept visible so support is not overclaimed.
Candidate increase
Only appears when the proof gate permits a public claim change; partial proof alone is not enough.
